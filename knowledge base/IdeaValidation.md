Why is it GenAI?

## Where GenAI lives in your system

**1. Claude as the Orchestrator Brain (core GenAI)**
The Lambda Orchestrator uses Claude (`claude-sonnet-4-6`) to *reason* about health data and make decisions. This is not rule-based logic — it's LLM reasoning. A traditional system would say "if heart rate > 120, trigger alert." Your system says "here's all the health context, Claude — what should we do?" That's GenAI.

**2. Twilio Calling Agent — AI-generated voice scripts**
Claude generates a *natural, compassionate, personalized* call script for each senior in real time before Twilio dials. The script changes based on their name, vitals, and situation. That's generative AI producing novel content, not a canned recording.

**3. Weekly AI Health Summaries**
The family dashboard shows an AI-written plain-English summary like *"Mr. Sharma had a stable week. Sleep improved 12%. Consider increasing walks."* Claude writes that fresh each week from raw data.
